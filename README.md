
# SPACE SURVIVOR 🚀

A 2D space survival game developed using Python and Pygame.

## About the Project

Space Survivor is an arcade-style game where the player controls a spaceship and avoids falling asteroids.

As the score increases, the difficulty increases because asteroids become faster and appear more frequently.

## Features

- Spaceship movement using arrow keys
- Asteroid generation
- Collision detection
- Increasing difficulty
- Score tracking
- High score saving
- Welcome screen and Game Over screen

## Technologies Used

- Python
- Pygame

## How to Run

1. Install Python.
2. Install the required library:

   pip install pygame-ce

3. Download or clone this repository.
4. Run:

   python space_survivor.py

## Controls

- LEFT ARROW: Move left
- RIGHT ARROW: Move right
- SPACE: Start game
- R: Restart game
